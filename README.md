🚀 Automação de Login SENAI
Projeto desenvolvido em Python com Selenium para automatizar o acesso às plataformas e contas de e-mail vinculadas ao SENAI.

📌 Sobre o projeto
O objetivo é simplificar o processo de login, permitindo que o usuário configure suas credenciais uma única vez e utilize a automação para abrir o navegador e acessar os serviços configurados.

O projeto foi pensado inicialmente para uso pessoal, em um computador específico, mantendo o perfil do navegador e as sessões autenticadas sempre que possível.

⚙️ Funcionalidades
🔐 Configuração inicial de e-mail e senha.
🌐 Abertura automática do navegador.
📧 Acesso automatizado às contas de e-mail e aos serviços configurados.
💾 Reutilização do perfil do navegador para preservar sessões autenticadas.
⚡ Redução da necessidade de realizar login manualmente a cada execução.
🛠️ Tecnologias utilizadas
Python
Selenium WebDriver
Navegador compatível com Selenium
📋 Pré-requisitos
Python instalado.
Navegador compatível.
Dependências do projeto instaladas.
Credenciais válidas para acessar os serviços necessários.
▶️ Como executar
Clone ou baixe o repositório.
Instale as dependências do projeto.
Configure as credenciais conforme as instruções do projeto.
Execute o script principal.
Aguarde a abertura do navegador e a execução das etapas automatizadas.
🔒 Segurança
Não compartilhe suas credenciais.
Não envie senhas ou cookies para repositórios públicos.
Proteja os dados armazenados no perfil do navegador.
Respeite as regras de acesso e de automação das plataformas utilizadas.
⚠️ Observações
A persistência do login depende da manutenção do perfil do navegador e da validade das sessões. Algumas plataformas podem exigir uma nova autenticação periodicamente.

O projeto foi desenvolvido para uso pessoal e pode precisar de adaptações para funcionar em outros computadores.
